## 3. App update boxes: mismatches and notes
M1 (CODE MISMATCH, ch02). Stale hepatic encephalopathy code K72.90 for catatonic disorder due to another medical condition; current is K76.82 (APA Sep 2022, section II.A, effective 2022-10-01). Locations:
- /home/claude/dsmvapp/data/db/disorders-ch02.js:289 (id catatonic-due-to-amc, specifiers) and :298 clue
- /home/claude/dsmvapp/data/ch02/guide.js:681
- /home/claude/dsmvapp/data/ch02/vignettes.js ~lines 370-389 (answer options use K72.90; correct option currently K72.90)
- ch17 already uses K76.82 correctly (guide.js:204, 130; cards-cases q17-07; db delirium update).

M2 (verification gap, ch17 guide.js:132, "No further changes in FY2027"). States Oct 2026 added no codes in F01-F09, G10, G20, G30, G31, G35, A81, B20, I67, R41, S06. Consistent with all evidence (hccbuddy says the only F-range change in FY2027 is new F64.A, "gender identity disorder, in remission"; FY2027 tabular shows F01-F03, F06.7x, G20, G35 structure unchanged from FY2026), but I could not read the official FY2027 addenda file, so this is not primary-verified for A81, B20, I67, R41, S06.

M3 (ch11, "unchanged through October 2026" for N39.498, R15.9, R32). F98.0/F98.1 confirmed in FY2027 tabular; the N/R codes were not checked in a primary source. APA lists no change. Likely correct.

M4 (ch10 minor wording, guide.js:76 "gave adults with pica and rumination codes in F50 rather than F98"). Correct for adults. Note APA 2024 PDF itself contains a typo "F50.893" for adult pica in some listings; F50.83 is correct (FY2027 tabular confirms).

Non-code APA criteria/text updates that the app does NOT mention (outside the code question; for the editor's awareness):
- Sep 2022: "commit suicide" wording in MDE criterion A9 / mixed features (ch3, ch4); PGD added to MDD differential (ch4).
- Sep 2023: delusional disorder and schizophrenia differentials re OCD/BDD/hoarding "absent insight/delusional beliefs" (ch2); conduct disorder differential, adjustment (ch.15 area).
- Sep 2024: adjustment disorder subtype wording (ch7); DMDD differential text (ch4); PGD normal-grief differential wording (ch7); Alzheimer's "both of" criteria (ch17, app has it); substance NCD coding note (ch17, app has it).
- Sep 2025: "-like" reworded other specified examples: cyclothymic-like (ch3 p168), depressive-like episode (ch4 p209), brief somatic symptom-like / illness anxiety-like (ch9 p370), bulimia nervosa-like / binge-eating-like of low frequency (ch10 p396), insomnia (ch12), subsyndromal delirium-like (ch17 p678; app has it); SUD severity wording in AUD, inhalant, sedative specifiers (ch16 pp547, 555, 602, 622); Z65.8 renamed "Moral, Religious, or Spiritual Problem". Grep found none of the ch3/4/9/10/16 items in app data (ch17 delirium item is present).

## 4. Could NOT verify
- Official FY2026 and FY2027 ICD-10-CM addenda files (ftp.cdc.gov zips are blocked by the proxy, 403; cms.gov pages failed). The "no other F-code change" conclusion rests on APA's own lists (which cover all DSM-printed codes), one secondary changelog for FY2027, and a partial primary read of the FY2027 Tabular List.
- FY2026 (Oct 2025) F-range changes: no primary source. Secondary San Bernardino list shows no F codes (only Z59.86 -> Z59.861/.868/.869, G35 expansion, R11.16 cannabis hyperemesis syndrome, Z77.31/.39). An athenahealth blog claims FY2026 MDD/SUD-remission/anxiety changes; unsupported by every other source and not consistent with the FY2027 tabular, treated as unreliable.
- Whether R11.16 (cannabis hyperemesis, FY2026) is meant to be used with DSM cannabis disorders: no APA statement found; not a DSM-5-TR code.
- FY2027 F64.A (in remission) is from one secondary source plus the tabular listing F64.A; it is Gender Dysphoria (ch14, out of scope).
- Fall/March 2023-2025 interim APA notices other than the PDFs above: none found; APA page shows no 2026 update as of this research.
- NSSI / suicidal-behavior codes: R45.88 NSSI not mentioned in any APA update; T14.91XA/XD correction found (ch21, out of scope). Not independently checked in the tabular.
- Printed (March 2022) code for each disorder was not checked against the book itself; "print" values come from APA's old-code column.
- F39, F43.10, F60.x, F21, F06.1, F42.x, F45.22 "no change": inferred from absence in all APA lists and presence in FY2027 tabular (F39, F21, F06.1, F60.0-.9, F60.81, F60.89 seen); F42.x, F43.10 and F45.22 seen as present in a summarized chunk only.
